# Support / 支持

## English

- Use **GitHub Issues** for reproducible bugs and focused feature requests.
- Use **GitHub Discussions** for architecture questions, design proposals, and general help.
- Use a **private Security Advisory**, not a public Issue, for vulnerabilities.

Search existing material first. For bugs, include the operating system, GPU, Unity/OpenVSP/Python versions, exact command, expected and actual behavior, and relevant sanitized logs. State whether the problem occurs in a clean checkout without `Library`, `work`, or `bin`.

This is a community-maintained research project. Support is provided on a best-effort basis without a guaranteed response time. No public support email or private telemetry channel is used.

## 中文

- 可复现的 Bug 和聚焦的功能请求请使用 **GitHub Issues**。
- 架构问题、设计方案和一般帮助请使用 **GitHub Discussions**。
- 安全漏洞请使用 **私密 Security Advisory**，不要创建公开 Issue。

提问前先搜索已有内容。报告 Bug 时，请提供操作系统、GPU、Unity/OpenVSP/Python 版本、准确命令、预期与实际行为，以及脱敏后的相关日志，并说明在没有 `Library`、`work` 和 `bin` 的全新克隆中是否仍能复现。

本项目是由社区维护的研究项目，支持按可用时间尽力提供，不保证响应时间。项目不公开支持邮箱，也不设置私密遥测渠道。
