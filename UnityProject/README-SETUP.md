# UnityProject setup / Unity 工程说明

Open this directory with **Unity 2022.3.62f3c1**. The main scene is `Assets/Scenes/Flight_Phase2.unity`; forest, island, and alpine environments are switched at runtime.

使用 **Unity 2022.3.62f3c1** 打开此目录。主场景为 `Assets/Scenes/Flight_Phase2.unity`，森林、海岛和雪谷在运行时切换。

- English: [Getting started](../docs/getting-started.md) · [Testing](../docs/testing.md)
- 中文：[入门指南](../docs/zh-CN/getting-started.md) · [测试指南](../docs/zh-CN/testing.md)

Use D3D12 and do not add `-nographics` to rendering or PlayMode commands. Do not open the same project in multiple editor instances.

请使用 D3D12，渲染或 PlayMode 命令不要添加 `-nographics`，也不要同时打开多个相同工程的编辑器实例。
